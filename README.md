# GlassiumOS-V4.0

**GlassiumOS-V4.0** is a modern 2.5D Glassmorphism Web Operating System built with Vite, React, TypeScript, and Tailwind CSS.

## Key Features
- **Brand Identity — The Fluid "G"**: Custom 2.5D liquid-glass ribbon monogram with Neon Purple (`#d946ef`) ➔ Amethyst (`#8b5cf6`) ➔ Translucent Cyan (`#06b6d4`) gradients and specular highlights.
- **2.5D Glassmorphism UI**: Translucent frosted-glass windows, taskbar, and controls (`bg-slate-900/40 backdrop-blur-md shadow-[inset_0_1px_1px_rgba(255,255,255,0.2)]`) with real-time SVG displacement refraction.
- **Integrated Taskbar & App Search**: Curated essential applications with a borderless 2.5D glass search bar (`検索`) for instant app launching.
- **Real System Settings**: Fine-grained control over **Display & Wallpaper** (including 2D Interactive Aurora & 2.5D Glass Physics), **Volume & Sound** (Web Audio API synthesizer), and **Theme** (Dark/Light mode & shell layouts).
